# Day 3 — Agile & Scrum Training Tasks

## Overview

Day 3 covers Agile and Scrum fundamentals applied across three domain scenarios. Each set walks through the full backlog lifecycle:

1. Product Vision & Stakeholders / Roles
2. Epics & User Stories
3. INVEST Review
4. Acceptance Criteria
5. Prioritisation & Estimation
6. Definition of Ready (DoR) & Definition of Done (DoD)
7. Backlog Table
8. JIRA Screenshots (placeholder)

## Sets

| Set | Domain | Key Focus |
|-----|--------|-----------|
| Set1_OnlineGrocery | Online Grocery Store | Product vision, roles, prioritisation + estimation |
| Set2_InsuranceClaims | Insurance Claims Processing | Vision, Agile vs Waterfall, estimation |
| Set3_HospitalAppointment | Hospital Appointment System | Vision, stakeholders, roles, prioritisation + estimation |
