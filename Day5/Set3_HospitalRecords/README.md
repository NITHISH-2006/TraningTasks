# Day 5 Set 3 - Hospital Patient Records

## Scenario
Normalize a wide hospital visits sheet into Patient/Doctor/Department/Visit/Billing and document DDL lifecycle and SQL vs NoSQL.

## Deliverables
- `schema.sql` - schema with valid visit dates, non-negative bill amounts, default bill status `OPEN`
- `seed_data.sql` - sample data (>=10 rows per table)
- `notes/Normalisation.md` - decomposition steps to 3NF
- `notes/ER_Diagram.md` - ER diagram (Mermaid)
- `notes/SQL_vs_NoSQL.md` - comparison table
- `output/console_output.txt` - DB/table lifecycle steps, monthly patients and doctors-by-department queries
